# To-do List Sederhana

Aplikasi to-do list sederhana dengan JavaScript (console).

## Fitur

- Menambah tugas (`tambahTugas`)
- Menampilkan semua tugas (`tampilkanTugas`)
- Menghapus tugas berdasarkan nomor (`hapusTugas`)

## Cara menjalankan

```bash
node index.js
```

## Contoh penggunaan

```js
tambahTugas("Belajar JavaScript");
tampilkanTugas();
hapusTugas(1);
```
